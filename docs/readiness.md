# Текущее состояние и ограничения

На 11 октября 2026 публично опубликована **Sites v19, runtime 7**: https://fsp.kosarevsky.dev/. [Запись релиза](releases/2026-10-11-v19.md) фиксирует происхождение исходников, публикацию и точный объём проверок. Документационные изменения сами по себе не публикуют новый сайт.

## Проверено

- **Исходники.** На head PR #16 прошли 470/470 тестов без пропусков, typecheck, lint, воспроизводимая подготовка Sites, сборка, миграции и фактический HTTP-запуск. [CI](https://github.com/agent-axiom/axiom-lct-fsp/actions/runs/38167936973). Программные тесты используют синтетические данные и перехват почтового провайдера; они не доказывают доставку или профессиональную валидность оценки.
- **Публичный сайт v19.** В новом анонимном браузере проверены `/`, `/account`, `/account/verify`, `/privacy`: HTTP 200. Четыре приватных/служебных API без авторизации вернули 401. Ссылка «Личный кабинет» ведёт на `/account`. На ширине 390 px горизонтального переполнения и ошибок JavaScript не выявлено. Проверка не отправляла почту и не входила в настоящие сессии.
- **Email-регистрация.** Два согласованных Gmail-ящика получили письма с восьмизначными кодами; пользователь подтвердил открытие кабинетов кандидата и работодателя. В базе подтверждены два проверенных аккаунта и два использованных регистрационных запроса. Проверка сделана на v18/runtime 6; далее runtime 7 открыл регистрацию для всех корректных email. v19 сохранил настройки и изменил только интерфейсные тексты/ссылку на кабинет. Это не повторная проверка Gmail на v19 и не проверка всех почтовых доменов.
- **Синтетический сценарий.** Профиль кандидата и PDF с кириллицей, учебный тест выбранной категории, история попыток, согласие и публикация, объяснимый подбор и фильтры, сохранённые запросы, предложение с RUB/месяц и gross/net, принятие/отказ, ограниченное раскрытие контакта и его отзыв проверяются на вымышленных данных. Гостевое переключение ролей не является входом двух настоящих независимых пользователей.

## Остаётся открытым

- **Доставка Yandex.** Проверенные адреса получили отказ SMTP `554 5.7.1` — подозрение на спам, в том числе после перехода к короткому письму без ссылок. Причина не устранена. Принятие запроса Resend не равно получению письма.
- **Полный реальный найм.** Для двух подтверждённых Gmail-аккаунтов ещё нужно пройти профиль/согласие/тест → поиск → предложение с зарплатой → принятие/отказ → контакт и отзыв согласия. Выход и повторный вход также не проверены. Регистрация и открытие кабинетов не закрывают эти пункты.
- **Грейды.** Пороги и учебные задачи не доказывают уровень реального специалиста. Заучивание, повторяемость и соответствие сложности заявленным уровням остаются рисками. Количество шаблонов не равно количеству независимо валидированных компетенций.
- **Подбор.** Словарь и конструкции свободного текста ограничены. Неподдерживаемое обязательное условие помечается как непроверенное, а не как отсутствующий навык; выдача и балл не гарантируют полного соответствия вакансии. Авторские регрессионные метрики не заменяют независимую проверку качества найма.
- **ФСП.** Достижения DEMO синтетические; настоящий реестр не подключён. Командный результат не доказывает личный вклад. Отсутствие истории ФСП допускается.
- **Эксплуатация.** Production-нагрузка, универсальная доставляемость, восстановление/смена email, самостоятельное удаление аккаунта и юридическое соответствие не заявляются. Мобильная проверка одного разрешения не заменяет проверку всех устройств.
- **Сдача.** На последней проверке репозиторий оставался приватным; доступ жюри ещё нужно подтвердить. Данные команды, презентация PPTX/PDF, окончательные ссылки и подтверждение подачи требуют завершения. Обязательный шаблон презентации в проверенном ТЗ не указан. [Чек-лист](final-submission-checklist.md).

## Режимы и границы данных

На публичном `/account` работает вход по восьмизначному одноразовому коду, без пароля. Один email закрепляет одну роль; код привязан к браузеру, действует 15 минут и блокируется после пяти неправильных попыток. Ответ на запрос не содержит кода. Регистрация требует актуального согласия с политикой. [Инструкция](public-email-account-runbook.md).

Гостевое демо остаётся отдельным пространством на два часа. В нём разрешены только вымышленные профили и адреса `@example.test`; почта не отправляется. Публикация профиля и раскрытие подтверждённого контакта в реальном кабинете требуют предусмотренного согласия.

Прототип не предназначен для реальных кадровых решений. Юридическое соответствие, включая 152-ФЗ, и полная готовность к обработке персональных данных не заявляются. Ручное заполнение резюме реализовано; распознавание PDF-резюме, рабочая ATS-интеграция и антифрод остаются дополнительными возможностями.
