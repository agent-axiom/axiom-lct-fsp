# Матрица соответствия ТЗ

| Требование | Статус | Ограничение |
|---|---|---|
| Два ролевых кабинета | Демо работает | Демо активно; отдельные role-bound ChatGPT-аккаунты и нормализованный API подготовлены, реальный режим выключен |
| Регистрация email | Частично | Демо активно; настоящие challenge/outbox и Resend-adapter подготовлены, провайдер/отправка выключены |
| Ручное резюме | Работает | Только синтетические поля |
| Авто-PDF профиля | Работает | Только собственный профиль |
| Опрос/выбор грейда/тест | Работает | 2 специализации, 3 грейда, 144 проектных шаблона, 12 заданий/попытку, 8 обязательных прикладных |
| Категория по тесту | Работает | Каждый навык ≥2/3, общий балл ≥75; пороги не валидированы экспертами |
| Провал без принудительного понижения | Работает | Кандидат выбирает следующую попытку |
| Ограничение смены грейда | Работает | 90 дней после успешной смены |
| История попыток | Работает | Исходные профили имеют синтетический исходный балл |
| Карточка доказательств | Работает | Одна успешная попытка, дата/банк/баллы навыков; синтетика и недоступные доказательства отделены; без вопросов и ключей |
| Две тестовые роли | Демо + HTTP/SQLite проверка | Контролируемые fixtures; не live-email и не браузерный e2e |
| Поиск/фильтры/объяснимость | Работает | Специализация/грейд/стек/опыт; простые отрицания/необязательность; альтернативы и сложные условия требуют уточнения; benchmark только синтетический |
| Приглашение без вакансии | Работает | Приглашения в приложении; внешние уведомления не включены |
| Зарплата от–до RUB | Работает | Серверная валидация |
| Статусы обеим сторонам | Работает | Обновляются после действий/перезагрузки |
| Контакты после согласия | Работает | Серверный DTO и отрицательные тесты |
| Приватность/согласие | Работает в демо | Не юридическая оценка 152-ФЗ |
| Нет истории ФСП | Работает | Никакого бонуса или штрафа; отдельный фильтр |
| Интеграция ФСП | Демо-адаптер | Нет реального API и верификации |
| Регулярные задания | Не реализовано | Опционально для MVP |
| Вакансии/отклики | Не реализовано | Опционально для MVP |
| Резюме из PDF | Не реализовано | Альтернатива ручной форме |
| OpenAPI | В комплекте | Схема демонстрационного API |
| Docker | Подготовлен | Не проверен в текущей среде |
| Нагрузка/валидность оценок | Не доказана | Нужны реальные независимые проверки |
