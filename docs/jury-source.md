## Текущий код и записанное происхождение

Демо по ссылке выше обновляется отдельно от GitHub. Точную опубликованную версию и исходный commit нужно брать из записи успешной публикации. Выбранный deployment-профиль записывает SOURCE-PROVENANCE.json: исходный GitHub commit, базовый снимок, список миграций и SHA-256 каждого исходного файла. Этот файл находится в подготовленном deployment-архиве; он не означает, что соответствующая версия уже опубликована.

Канонический код сохраняет гостевой UX, изоляцию ролей, позднейшую почтовую логику и две отдельные owner-only диагностики. [Проверка доменного отправителя](owner-domain-email-test.md) не переиспользует старую квитанцию и не включает реальную регистрацию или общую отправку. Все маршруты этих диагностик описаны в [OpenAPI](openapi.json).

Для существующего сайта с историей v12 применяется [явный профиль миграций sites-v12](../migration-profiles/sites-v12/README.md); обычную mainline-цепочку нельзя подставлять в эту базу. [Документ о расхождении историй](deployment-lineage.md) фиксирует исходное ограничение. Для обычного локального запуска используется чистая mainline-база. Публикация исходников сама по себе не включает почту, не меняет домен и не отправляет заявку.

## Честные ограничения

Люди, профили и начальные оценки синтетические. Демо-код и mock-провайдер не доказывают владение email или настоящую доставку. Разовая диагностика владельцу не равна регистрационному пути. Реальные аккаунты и общая почта выключены. Реестр ФСП не подключён. Учебные грейды и авторские метрики не валидированы для реальных кадровых решений.

Исторические документы сохраняют собственные версии и даты; старые числа тестов нельзя выдавать за текущий прогон. Браузерные проверки v12 не доказывают прохождение новой согласованной ветки. Подготовка репозитория не является финальной отправкой на конкурс.

## Публикация и лицензии

Репозиторий пока остаётся приватным по решению владельца. Жюри сможет прочитать приватный код только при предоставленном доступе. Публичность запланирована после подтверждённого дедлайна и проверки истории, не раньше.

Сохранены MIT notices OpenAI/shadcn, SIL OFL JetBrains Mono и notice шрифта PDF. Новая лицензия основному коду не назначалась. Предварительная проверка снимка не нашла реальных ключей или частных QA-идентификаторов; это не гарантия отсутствия секретов во всей истории Git.
