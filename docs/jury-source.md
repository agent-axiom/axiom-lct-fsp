## Проверенное и ограничения

Публичная email-регистрация включена. На двух согласованных Gmail-ящиках подтверждены регистрационные письма, ввод кодов и открытие кабинетов кандидата и работодателя; в базе проверены два подтверждённых аккаунта и два использованных регистрационных запроса. Эта приёмка выполнена на v18/runtime 6; runtime 7 затем открыл регистрацию для всех корректных email, а v19 изменил только тексты и ссылку на кабинет. Сквозной найм между реальными аккаунтами и выход/повторный вход ещё не проверены. Для проверенных адресов Yandex отказ SMTP `554 5.7.1` остаётся неустранённым.

Свежая анонимная проверка v19 подтвердила четыре публичные страницы с HTTP 200, четыре запрета для приватных/служебных API с 401 и мобильный вид 390 px без переполнения и ошибок JavaScript. Почта в этой проверке не отправлялась; реальные сессии не использовались.

Демо-профили и достижения синтетические. Настоящий реестр ФСП не подключён. Учебные грейды и авторские метрики не валидированы для реальных кадровых решений. Подбор использует ограниченный словарь и явно показывает распознанные непроверенные обязательные условия; универсальное понимание свободного текста не заявляется. Получение отдельного diagnostic-письма не заменяет регистрационную приёмку.
