# Подбор v0.6: процедура, результаты, слабые случаи

6 октября 2026. Базовый исходник: v0.5, commit 1fd178b32ad72c9cc3d31647465c93e8940326d4. Точный старый matcher сохранён в `scripts/evaluation-baselines/matching-v05.mjs`. Формальные правила разметки, происхождение и ограничения описаны в `matching-quality-methodology.md`.

## Протокол

Независимый от реализации рабочий проход подготовил 36 синтетических профилей и 36 запросов с полными 1296 авторскими метками 0–3. Автор знал задачу и интерфейс, но не запускал алгоритмы. Метки механически развёрнуты из явной рубрики, а не получены от 1296 разных экспертов. Данные и SHA-256 зафиксированы до изменения matcher в 18:07:35 UTC. Старый набор 10×12 сохранён.

Train/development/heldout — по 12 запросов, общий пул профилей. Основная P@5 считает label≥2, вспомогательная legacy P@5 — label>0; пустые позиции считаются нерелевантными. NDCG@5 использует gain=2^label−1. Нулевой IDCG не превращается в искусственную единицу: такой запрос остаётся в P@5, исключается из среднего NDCG с явным знаменателем.

Сначала просмотрены только 24 train/development-запроса. В исходной версии выявлено: «Python или Go» целиком терялось в скоринге. Добавлена строго ограниченная OR-пара, где достаточно одного навыка; отрицания, optional и сложные списки по-прежнему не угадываются. DEMO-компонент ограничен +5 и точной категорией без missing-требований. Далее файлы реализации зафиксированы SHA в `matching-selection-manifest.json`; только после этого проведена однократная heldout-оценка. После неё matcher не настраивался.

## Результаты

| Срез | P@5 v0.5 → v0.6 | NDCG@5 v0.5 → v0.6 | Потолок P@5 |
|---|---:|---:|---:|
| 24 train/development | 0,825 → 0,850 | 0,964180 → 0,986561 (23 запроса) | 0,900 |
| 12 heldout | 0,866667 → 0,866667 | 0,996623 → 0,996623 (12 запросов) | 0,883333 |

Нарушений допуска/видимости: 0 во всех четырёх прогонах. Низкий потолок некоторых запросов обусловлен тем, что подходящих кандидатов меньше пяти. На фиксированной отложенной части агрегированного улучшения НЕТ. Достижения меняют баллы и парные порядки согласно политике, но сами по себе не улучшили P@5/NDCG на этом наборе. Улучшение доступной части связано с простым OR-запросом, использованным при разработке, и не является независимым доказательством обобщения.

## Слабые случаи, которые не скрываем

- d03, «Backend; Python или Go; SQL обязателен»: NDCG 0,485229 → 1,000; P@5 0,4 → 1,0. Это development-кейс, по которому исправлялся parser.
- d11, Junior Frontend strength: NDCG 0,872712; P@5 0,6. Сильный балл соседней категории может поднять слабее соответствующий профиль, поскольку грейд в тексте — мягкий признак; для строгой категории нужно выбрать явный фильтр. Не исправлялось под heldout.
- h04, Senior Frontend CSS Accessibility strength: NDCG 0,959474; P@5 0,8. Осталось расхождение с авторским порядком силы профиля. Это наблюдение финального holdout, не основание подкрутить веса и повторно назвать результат независимым.
- d08, обязательный Rust: подходящих кандидатов нет, NDCG=null. Ограниченный словарь не распознаёт Rust из текста и возвращает не соответствующих этому намерению кандидатов с общим предупреждением. Явный фильтр стека Rust даёт пустую выдачу. Автоматическое понимание произвольных требований не заявляется.
- Сложные OR-группы, отрицательные фильтры и верхняя граница стажа не реализованы полностью; UI предупреждает о ручной проверке.

## Воспроизведение

`npm run evaluate:quality` повторяет только доступную часть. Полные сохранённые результаты: `matching-quality-*-visible.json`, `matching-quality-*-heldout.json`; сводка: `matching-quality-evaluation.json`. Скрипт проверяет SHA замороженного fixture перед запуском. Heldout требует отдельного `--split heldout --acknowledge-heldout`; повторная проверка после новых изменений уже не является новым независимым экспериментом.

Это внутренний регрессионный benchmark. Он не измеряет качество реального найма, справедливость к группам людей, профессиональную пригодность или статистически надёжный эффект. Для следующего вывода нужны новая скрытая выборка и внешняя разметка.
