## Программные и HTTP-проверки

На этом исходнике прошли 195 тестов, typecheck, lint, production build, миграции и настоящий локальный HTTP-запуск. [CI проверенного merge-коммита](https://github.com/agent-axiom/axiom-lct-fsp/actions/runs/37734640908). Результат относится к указанному коммиту; для последующих изменений проверяйте их собственный CI.

В изолированном изменении request-time email-dispatch полный набор вырос до 229 тестов, включая 34 новых HTTP/migration-проверки с синтетическими данными и mock транспорта. Typecheck, lint и сборка проходят; браузерный UI-прогон этого изменения заблокирован средой. Это не подтверждение реальной доставки. Методика и границы: [email-request-dispatch.md](email-request-dispatch.md).

```sh
npm run install:ci
npm test
npm run typecheck
npm run lint
npm run evaluate
node scripts/evaluate-matching-quality.mjs --module lib/domain.mjs --split visible --label v0.6
npm run evaluate:assessment-quality
node scripts/verify-two-role.mjs
npm run build
node scripts/migrate-local.mjs
node scripts/verify-clean-launch.mjs
```

Assessment-evaluator обновляет timestamp в сохранённом локальном отчёте. Для чистого сравнения исходников запускайте его в отдельном checkout. Команды `--write` предназначены для явного обновления отчётов.

`verify-clean-launch.mjs` проверяет главную без авторизации (200), отказ в доступе к личному workspace (401) и гостевой API (200). `verify-two-role.mjs` проверяет роли, доказательства, приглашения, согласие и границы доступа в HTTP/SQLite. Внешние письма не отправляются.

## Браузер

7 октября пройден отдельный desktop-прогон гостевого сценария: 32 успешных сценария, три UX-дефекта и одно некритическое наблюдение в консоли. После исправлений Sites v9 прошёл 14 из 14 целевых повторных проверок:

- ответы сохраняются при refresh и навигации в той же вкладке;
- отправка, смена роли и сброс не восстанавливают старый черновик;
- после отзыва согласия контакт скрыт и текст объясняет причину;
- Escape/X возвращают фокус к исходной кнопке; фокус остаётся внутри открытого диалога.

Это не проверка двух настоящих аккаунтов. Мобильный viewport, реальные письма, внедрённые сетевые отказы, временное истечение и browser-fallback при исчезнувшей кнопке не проверены. Предупреждение Vinext RSC prefetch не объявляется исправленным. Сохранённый [план браузерной проверки](browser-verification.md) относится к более раннему этапу; актуальный итог приведён здесь.

## Качество алгоритмов

Программные тесты не доказывают профессиональную валидность грейда или качество реального найма. В репозитории сохранены авторские синтетические процедуры: [assessment v4](assessment-quality-v4.md), [matching](matching-quality.md), [методика matching](matching-quality-methodology.md).

Старый benchmark 10 профилей × 12 запросов является regression-набором. В наборе 36 × 36 отложенная часть v0.6 не показала улучшения относительно v0.5. Повторная настройка на просмотренных heldout-результатах не создаёт независимую проверку.

Ограничения: [readiness.md](readiness.md). Исторические протоколы и результаты не удаляются при обновлении README.
