# Проверки версии0.3 — 5 октября2026

## Выполнено на финальном коде

- 83/83 автоматических теста: 43 доменные регрессии (включая текст UI и изоляцию истории работодателей), 9 тестов reference account-модели, 4 исходные SQLite-проверки, 12 normalized-account/SQLite integration, 8 transactional-outbox, 7 HTTP-handler тестов.
- TypeScript: пройдено. ESLint: пройдено без ошибок/предупреждений линтера. Production-сборка Vinext/Worker: пройдено.
- Реальные SQL-миграции 0000 и0001 выполнялись в SQLite in-memory, с foreign keys. Проверены unique identity/email, rollback account+profile+challenge+outbox при сбое, CAS, scoped reads и EXPLAIN использования индекса.
- Проверен нормализованный сценарий двух синтетических principal: регистрация, mock-письмо, одноразовая проверка, тест, доказательства навыков, поиск, приглашение, принятие и отзыв согласия. Это integration тест, не браузерный e2e и не реальные пользователи.
- Worker очереди: off→0 вызовов транспорта, idempotency/stable payload, transient/permanent failures, backoff, истечение lease, падение после HTTP до фиксации, два параллельных worker, expiry и смена token secret.
- HTTP handlers проверены in-process:401/403/404/413, Origin, 16000байт UTF-8, отсутствие actor-cookie, данных чужого пользователя/очереди/секретов, собственный PDF.
- Синтетический benchmark:10 кандидатов×12 запросов; Precision@5 0.600→0.950, NDCG@5 0.618→1.000. Dataset, labels и скрипт сохранены.
- В v0.2 выполнены генерация, извлечение кириллицы и визуальный PNG-контроль PDF обычного и длинного двухстраничного профиля. В v0.3 PDF собственного аккаунта повторно сгенерирован на синтетическом fixture, извлечён текст и визуально проверен PNG: 4 блока навыков и маркировка экспериментальной оценки без ложного утверждения о синтетических данных.

## Не проверено / ограничения

- Browser/mobile e2e и визуальный UI-контроль не подтверждены. Предыдущие ограничения: Chromium socket operation not permitted, cloud browser loopback ERR_BLOCKED_BY_CLIENT. Обходов не предпринималось.
- Попытка прямого вызова собранного Worker в обычном Node остановилась на неподдерживаемом cloudflare: ESM scheme; это не Worker-эмулятор. Успешный локальный smoke всего собранного Worker не заявляется. Сам build прошёл, отдельные HTTP handlers покрыты in-process тестами.
- Runtime WebMCP, Docker, нагрузка и обработка реальных данных не проверялись. Глобальный CAS ограничивает write-throughput, нагрузочные SLO не установлены.
- Реальные аккаунты и внешний email OFF. Почтовый провайдер, domain/DNS, runtime secrets, операторские политики, расписание/защищённый вызов worker и настоящее письмо не настраивались. Resend HTTP использован только через mock в тестах.
- GitHub export предыдущей операции не повторялся; видимость репозитория и merge не менялись.

## Трактовка

Порог ≥75 в целом и ≥2/3 по каждому навыку — проектное решение. Benchmark небольшой, размечен разработчиком вместе с реализацией; независимого/отложенного набора и экспертной валидации нет. Идеальный NDCG на нём не доказывает реальное качество найма. Результаты не являются подтверждением профессиональной пригодности, отсутствия дискриминации или соответствия152-ФЗ.
