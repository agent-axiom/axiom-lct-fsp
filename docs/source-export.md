## Чистая проверка

Используйте Node.js 24.19.0 и npm из этого дистрибутива. Нужен доступ к публичному npm registry для установки зафиксированных lockfile-зависимостей. Секреты, аккаунт Cloudflare и email-провайдер не нужны для синтетической локальной проверки.

```sh
npm run install:ci
npm test
npm run typecheck
npm run lint
npm run evaluate
node scripts/evaluate-matching-quality.mjs --module lib/domain.mjs --split visible --label v0.6
npm run evaluate:assessment-quality
node scripts/verify-two-role.mjs
npm run build
node scripts/migrate-local.mjs
node scripts/verify-clean-launch.mjs
```

Последний шаг запускает сервер только на loopback, проверяет анонимную главную, гостевой API и отказ доступа к личному workspace, затем завершает сервер. Это реальная HTTP-проверка, но не браузерный E2E и не проверка доставки почты. Результаты CI относятся только к commit, указанному в запуске; наличие workflow не означает, что он уже прошёл.

Для интерактивного локального демо после миграций выполните `node scripts/local-demo.mjs` и откройте `http://localhost:8888`. Локальный прокси добавляет вымышленную identity и не предназначен для публичного сервера. Docker-инструкция в README остаётся отдельным способом запуска; её прохождение нельзя выводить из успешного Node.js smoke test.

## Состав и ограничения

- Сохранены исходные файлы, тесты, зафиксированные синтетические fixtures, миграции, lockfile, описание API и примеры настроек.
- Настоящие `.env`, токены, runtime-состояние, базы данных, `node_modules`, результаты сборки и локальные служебные каталоги не входят в экспорт.
- `public/fonts/profile.ttf` и встроенная копия в `lib/profile-font.ts` используют лицензию из `docs/FONT-LICENSE.txt`. JetBrains Mono поставляется с `docs/JETBRAINS-OFL.txt`; сохранены notices подключённых исходных компонентов.
- Публикация исходников не включает реальную почту, не меняет доступ к сайту или репозиторию и не подтверждает прав доступа у жюри.
- Основной программный код не получает новую лицензию этим экспортом. Выбор лицензии владельцем и доступ проверяющих решаются отдельно.
