# ФСП / ТАЛАНТЫ

MVP обратного найма: кандидат проходит учебную проверку навыков, работодатель получает объяснимую подборку и отправляет предложение с зарплатой. Контакт открывается после принятия приглашения при действующем согласии.

[Открыть сайт](https://fsp.kosarevsky.dev/) · [Личный кабинет](https://fsp.kosarevsky.dev/account) · [Локальный запуск](docs/development.md) · [API](docs/openapi.json)

## Опубликованная версия

На 11 октября 2026 опубликована **Sites v19, runtime 7**. [Запись релиза и границы проверок](docs/releases/2026-10-11-v19.md) содержит точные версии, commit и результаты. На исходнике PR #16 прошли 470/470 тестов, typecheck, lint, сборка, проверки обеих историй миграций и фактического HTTP-запуска. Это технические проверки, не точность найма.

## Попробовать

Демонстрация доступна без регистрации. Она создаёт отдельное гостевое пространство на два часа. Используйте только вымышленные данные и адреса `@example.test`.

1. В роли кандидата заполните профиль, пройдите тест и включите публикацию с согласием.
2. В роли работодателя задайте потребность и фильтры, посмотрите причины подбора.
3. Отправьте предложение с зарплатой, примите его за кандидата и проверьте раскрытие контакта.

В демо также есть готовые синтетические профили. PDF-профиль, история тестов, сохранённые подборки и статусы приглашений доступны в кабинетах.

## Вход по email

[Регистрация](https://fsp.kosarevsky.dev/account) открыта для корректных email. Для первого входа выберите роль, укажите имя или компанию и примите текущую политику данных. Введите **восемь цифр из письма** на той же открытой странице и в том же браузере. Пароль не нужен. Код действует 15 минут и используется один раз; один адрес закрепляет одну роль. После обновления страницы потребуется запросить новый код.

На двух согласованных Gmail-ящиках подтверждены получение регистрационных писем, ввод кодов и открытие кабинетов кандидата и работодателя. В базе подтверждены два аккаунта и два использованных регистрационных запроса. Эта проверка выполнена на v18; v19 меняет только интерфейсные тексты и ссылку на кабинет, сохраняя runtime 7. **Полный найм между этими реальными аккаунтами и выход/повторный вход ещё не проверены.**

Для проверенных адресов с обслуживанием Yandex получен отказ SMTP `554 5.7.1` — подозрение на спам. Проблема доставки на них не устранена. Принятие запроса Resend не означает получение письма; доставка на все домены не заявляется.

## Запустить локально

Нужны доступ к репозиторию, Node.js 24.19.0 и npm. После клонирования:

```sh
npm run install:ci
npm run build
node scripts/migrate-local.mjs
node scripts/local-demo.mjs
```

Откройте http://localhost:8888. Локальный прокси использует вымышленную идентичность; не выставляйте его в интернет. Секреты и email-провайдер для демо не нужны. Подробности и Docker: [разработка](docs/development.md).

Для обновления существующего сайта используется [профиль миграций sites-v12](migration-profiles/sites-v12/README.md) с историей `0000–0006`. Чистая mainline-база использует свою историю; не применяйте её поверх базы Sites. Подготовленный профиль записывает происхождение и SHA-256 исходников в `SOURCE-PROVENANCE.json`.

## Границы готовности

- Реестр ФСП не подключён. Достижения DEMO вымышленные и не подтверждают реальные соревнования или личный вклад.
- Грейды учебные: профессиональная валидность и устойчивость к заучиванию не доказаны. Не используйте прототип для реальных кадровых решений.
- Подбор понимает ограниченный словарь. Нераспознанные обязательные условия показываются как непроверенные; это не доказательство отсутствия навыка. Сложный свободный текст требует ручной проверки.
- На v19 проверены четыре публичные страницы, запреты для неавторизованных API и мобильный вид шириной 390 px; ошибок JavaScript и горизонтального переполнения не выявлено. Это не полная браузерная приёмка реального найма или production-нагрузки.
- Доступ жюри к репозиторию и материалам, окончательная презентация и подтверждение отправки заявки проверяются отдельно. На последней проверке репозиторий оставался приватным; намерение открыть его не является подтверждённым доступом.
