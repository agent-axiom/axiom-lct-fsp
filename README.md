# ФСП / ТАЛАНТЫ

MVP обратного найма: кандидат проходит учебную проверку навыков, работодатель получает объяснимую подборку и отправляет предложение с зарплатой. Контакт открывается после принятия приглашения при действующем согласии.

[Открыть демо](https://axiom-fsp-talent.major-tick-1728.chatgpt.site) · [Локальный запуск](docs/development.md) · [Проверки](docs/testing.md) · [API](docs/openapi.json)

## Версия для ревью

Текущий демо-сайт доступен по ссылке выше; его точная версия определяется записью публикации, а не номером в README. [Происхождение исходников и маршрут проверки жюри](docs/jury-source.md). Снимок Sites v12 сохранён как историческая база. Для обновления существующего сайта используется [явный воспроизводимый профиль миграций](migration-profiles/sites-v12/README.md), который записывает исходный commit и хеши в SOURCE-PROVENANCE.json. По умолчанию локально используется чистая mainline-база. [Разовая проверка доменной почты владельца](docs/owner-domain-email-test.md) изолирована от общей отправки.

## Попробовать

Демо доступно без входа в ChatGPT. Оно создаёт отдельное гостевое пространство на два часа. Используйте только вымышленные данные и адреса `@example.test`.

1. В роли кандидата заполните профиль, пройдите тест и включите публикацию с согласием.
2. В роли работодателя задайте потребность и фильтры, посмотрите причины подбора.
3. Отправьте предложение с зарплатой, примите его за кандидата и проверьте раскрытие контакта.

В демо также есть готовые синтетические профили. PDF-профиль, история тестов, сохранённые подборки и статусы приглашений доступны в кабинетах.

## Запустить локально

Нужны доступ к репозиторию, Node.js 24.19.0 и npm. После клонирования:

```sh
npm run install:ci
npm run build
node scripts/migrate-local.mjs
node scripts/local-demo.mjs
```

Откройте http://localhost:8888. Локальный прокси использует вымышленную идентичность; не выставляйте его в интернет. Секреты и email-провайдер для демо не нужны. Подробности и Docker: [разработка](docs/development.md).

## Границы готовности

- Реальная почта и интеграция с реестром ФСП выключены. Демо-код не подтверждает настоящий email.
- Грейды учебные: профессиональная валидность и устойчивость к заучиванию не доказаны. Не используйте прототип для реальных кадровых решений.
- Подбор понимает ограниченный словарь. Жёсткие фильтры задаются явно; условия свободного текста требуют проверки.
- Программные и браузерные проверки описаны отдельно. Мобильный вид, реальная доставка писем и production-нагрузка ещё не подтверждены.

Подробнее: [текущее состояние и ограничения](docs/readiness.md).
